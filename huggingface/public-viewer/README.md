# NYK World Visual Explorer

An independent, unofficial portfolio project presenting versioned Knicks game analysis.
The viewer consumes the exact public payload recorded in `data/release-manifest.json`.
It does not contain official logos, photography, or a substitute sports-data API.

Data-derived outputs follow the source terms documented in the matching release. Original
viewer code is MIT licensed. This project is not affiliated with or endorsed by the NBA
or New York Knicks.
